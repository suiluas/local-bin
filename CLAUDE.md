# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Directory

This is `C:\Users\Admin\.local\bin` — the Claude Code CLI installation directory on Windows. It contains the Claude Code executable (`claude.exe`) and any previous versions (e.g., `claude.exe.old.*`).

There is no source code, build system, or tests here. This directory is managed by Claude Code self-update mechanism.
